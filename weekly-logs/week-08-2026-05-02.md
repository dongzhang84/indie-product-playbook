- **自定义域名切换**：vibe-reading.dev 正式上线（apex 主域，www 307 跳转），完整走完 STANDARD §12.B 流程（Vercel + Namecheap DNS + Supabase Auth URL 更新），记录了两个 Vercel 切换陷阱供后续 playbook 参考
- **Landing 冷启动彻底消灭**：原因是 `app/layout.tsx` 做了 async `getUser()` 导致全站强制 SSR，TTFB 800ms–1s；重构为新 `/api/me` 端点 + Nav 客户端 `useEffect` 拉取 auth 状态，layout 变为纯同步，首页变为静态预渲染（CDN HIT），TTFB 降至 ~120–155ms

- **Storage 孤儿 Bug 修复**：`claim.ts` 的 `storage.move()` 后 `update books` 未校验返回值，导致 DB 路径与 Storage 实际路径长期错位，历史积累 ~30MB 孤儿文件；修复 + 一次性清理脚本
- **Twitter 发布 → 33 新用户/24h**：产品发布贴当天带来约 33 个真实注册用户
- **冷邮件外联工具链，开源**：手动发邮件到第 8 封时已无法持续，写了两个脚本：
  - `draft-cold-emails.mjs`：从 Supabase 拉用户列表，对比 `sent-emails.json` 跳过已发，按中西文规则填姓名，生成 Template A / C 批次草稿
  - `send-cold-emails.mjs`：解析草稿，Gmail SMTP 逐条发送（5s pacing），成功记录写回 registry 保证幂等
  - 同步开源了多个只读运营探针脚本（用户列表 / bucket 状态 / 统计 / 重复检测）
