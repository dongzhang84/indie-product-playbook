# Week 10: Build Summary (5/16 - 5/22)

## Project 1: PhysLit — v0.2 执行完毕，v0.3 完整闭环

本周 PhysLit 是最活跃的项目（约 98 commits），连续完成两个实验版本。

**v0.2 执行（02_fmv 框架）**

假设物理法则为 F=mv（而非 F=ma），给模型一组现象，测试 LLM 能否从现象归纳出正确物理定律。三阶段（S1 归纳 / S2 公式化 / S3 预测）执行结果：GPT 全部通过，Claude 一个 fail，Gemini 拉胯——这是一道"送分题"，模型普遍能破译非标准物理框架。

**v0.3 设计 + 预注册 + 执行（03_decay 框架）**

新物理域：能量衰减框架（非力学，换一个物理学科维度）。实验设计采用单变量控制，treatment arm 与 02_fmv.2 treatment 字节级完全一致，仅切换物理框架。完整走完全流程：现象设计 → dry-run → 正式试验 → dual-judge（Claude-as-judge + GPT-as-judge）→ 人工审计 → 报告（2026-05-20）。两条预测在 judging 前锁定。

## Key Lessons This Week

- **PhysLit 节奏验证**：v0.2 和 v0.3 连续两个实验在一周内完成完整闭环（预注册 → 执行 → report），证明这套"小批次、强预注册"实验框架完全可以高频运行，不是一次性方法论
- **美国系列爆款逻辑持续**：法律/教育/医疗/移民四篇系统性深度文章已形成系列品牌效应，下一篇延续这个框架是有路径依赖的正确选择
- **SpaceX 立志传大修提示一个问题**：写作时去 PPT 化的重构成本很高，是否可以在初稿阶段就避免这种结构？需要在写作流程前端解决
- **Karpathy 分析帖的价值**：对业界大事件做冷静的组织/战略层面解读，而不是情绪化追捧或八卦，是这个账号在 AI 讨论区的差异化定位
