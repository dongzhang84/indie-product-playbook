## Project 3: Noether Decay — 独立建库，理论重构

本周 noether-decay 从 snowboat-blog 迁出成独立 repo，共 5 commits。

这不是一篇科普文章，而是一个理论命题的研究草稿。核心论点：**学习等于诺特荷的衰减**。神经网络训练是一个耗散动力系统——参数空间的重缩放对称性给出诺特守恒量 C，而学习真正发生的方向，恰好是 C 衰减的方向（由 weight decay 这个保守正则项强制打破对称驱动）。"守恒子空间"是网络的盲点，"衰减子空间"是它实际在学的方向。

本周主要进展：
- 建库，正文从 snowboat-blog 迁入 `docs/`
- README 改写为英文版（面向学术投稿方向）
- 加入 toy model 代码（`eight_theorems.py` / `check_friction.py` / `thm7_contrast.py`）和实验配图
- 重构主线：C 守恒改用代数恒等式（Du-Arora 方法）直接证，原 moment-map/诺特框架退为旁白；m / Q_N / 平衡律全降为背景附注；速率统一标记为 2μ

当前状态：早期草稿，结论在理想化条件下（各向同性、常数正则项）成立；推广至真实 SGD 是方向，尚未完成。

## Project 4: ThalesLab — 首次建库，第一个可视化上线

本周 thaleslab 第一次建库，1 commit，但完成度相当高。

定位：**"算得对、能交互的物理可视化"**——底下有真求解器在积分方程，不是预渲染动画。命名取自泰勒斯（第一个用理性而非神话解释自然的人）。

第一个作品（诺特定理）已完成：行星绕恒星 + 辛积分器（velocity-Verlet）保证守恒量不因数值误差漂移 + 实时双曲线显示 L（角动量）和 E（能量）。可以动态打破对称性——打破旋转对称，L 开始漂移，E 保持平坦；打破时间对称，E 漂移，L 保持——把诺特定理"眼见为实"。

Roadmap 三条路线（同一个内核，三种野心）：
- **路线 1**：可视化内容系列（给人看）
- **路线 2**：开源成"物理版 Manim"工具（给创作者/学生用）
- **路线 3**：精确物理引擎接口（给 AI/世界模型调用，作为"物理标准答案校验器"）——这是变现入口，也是和巨头有差异化的地方：英伟达做的是宏观机械力学，世界模型公司做不准相对论/场/天体物理，这一格是空的

## Twitter 本周思考（@snowboat84，6/13–6/19）

本周 Twitter 最重量级的输出是 #56《个人 AI 系统：哲学基础》，它不只是一篇文章，也是账号核心框架 Vibe OS 的第一次完整公开。另有五条独立推文横跨历史、生活和方法论。

**① Vibe OS 哲学宣言**（6/19，#56，12.6K 浏览）

本周最核心的原创思考。Vibe OS 是对"如何在 AI 时代保持'我'"这一问题的完整回答，构建了六层架构：

- **第一原则：我永远站在系统之外**。主体 vs 工具的区分是整套系统的宪法，"外包判断本身比外包执行危险得多"——作者本人亲历了开始让 AI 先出观点框架、再自己填内容的滑坡过程，后来立规矩：观点必须自己先成形，AI 只在有了立场之后介入
- **价值理性 vs 工具理性**（借韦伯概念）：AI 负责"是什么"（信息、执行），人负责"为什么"和"怎么样"（判断、意义、方向）。韦伯早在一百年前就判断，现代化是工具理性不断压倒价值理性的过程——AI 把这个趋势推到了人类史上最高点
- **两条输入线——Pulse Learning vs Deep Learning**：Pulse 以天为单位感知动态（X、热点、市场），Deep 以月为单位吃透系统（经典、理论）。关键设计：Pulse 里反复出现的主题，自动升级为 Deep 的选题——让快的那条线成为慢的那条线的雷达
- **由己及人**：真实痛点 → 持续自用 → 公开写作 → 受众 → 个人市场。凯文·凯利"一千个铁杆粉丝"是这条路的数学支撑。从自己需求出发的产品（"挠自己的痒处"），天然和受众的痛点重叠，绕开了"去市场上猜需求"的最大陷阱
- **个人市场 ≠ 公司**：两个不同终点之间隔着一道真实的鸿沟，把两者混为一谈会导致两种痛苦——要么把本来很滋润的个人市场往公司模式上掰拧巴，要么做到个人市场却因为"没成为一家公司"而觉得自己失败了
- **状态驱动 vs 任务驱动**：Vibe 的本质是状态，不是任务清单。"进了那个模式，系统就把对应的材料、工具、上下文都备齐，人和AI配合着，事情是流出来的，不是逼出来的"
