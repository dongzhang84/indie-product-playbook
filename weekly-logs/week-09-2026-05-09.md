# Week 9: Build Summary (5/9 - 5/15)

## Project 1: PhysLit — v0.1 结果出炉，v0.2 预注册锁定

**v0.1 完整报告（5/11）**

3 个前沿模型（Claude Opus 4.7 / GPT-5.5 / Gemini 3.1 Pro）× 5 次试验 × 4 个阶段，在亚里士多德力学框架下测试物理归纳推理能力。两项预测（预注册于 5/9）均已确认：

- **P1 CONFIRMED**：Claude 3/5 次、Gemini 3/5 次在 Stage 1 引入了训练数据中的"真实物理"概念（Newton Leak）——模型无法完全留在亚里士多德框架内推理
- **P3 CONFIRMED**：含错误试验中 7/10（70%）的模型在 Stage 4 自我反思时过度声称正确

方法论发现：两个 LLM judge（Claude-as-judge / GPT-as-judge）对 36.67% 的分类存在分歧，触发预注册规定的人工审计。单一 judge 的 LLM benchmark 在此类材料上不可靠。总计 180 次 API 调用，花费约 $14。

**v0.2 设计 + 预注册（5/12）**

在 v0.1 基础上新增"结构维度"：不仅检测内容禁忌词（Newton Leak），还检测生成的物理法则是否完整、非重复。Resolver 切换为 Gemini-2.5-pro（v0.2 的一处预定义偏差）。本周 PhysLit 共 40 commits。
