### Paper 2：Physics Model Library — **47 实质 commit，本周最重的一条线**

commit 分布：7/5 (12)、7/6 (8)、**7/7 (22)**、7/8 (5)，7/4 与 7/9–7/10 为 0。含 CI 自动 SPRINT 更新共 94 个。

这一周的性质变了：从"跑实验"变成"有可发表的结论，并开始写论文"。

**① 7/5 自曝泄漏，把结论推倒重做**

发现旧 Test 3 里 `emit = 1 − cell` 是硬编码——carrier-blind 的模型也能拿 100%，"学到了整合结构"这个结论是**空的**。于是把整个 Test 3 作废，重做到 finite-carrier BBS（守恒是结构性的 `k' = t − out`，上面还压着一个真正非平凡的残差）；作废的版本留作 appendix 存档，不删。

同日把核心主张也降级成诚实版：**从"打败 Transformer"改成"结构守恒在 compose 时不漂移"**——这是 scan 模型之间的效率 + 保证优势，不是屠榜。

补上 Test 4（对 GRU / LSTM / Mamba-SSM 的公平对比，Transformer 只留作 no-structure 参照）和 Test 5（5 seeds 严格化）。多 seed 把单 seed 的过度声明修回来了：**Test 3 精度 100 → 94±5，learned-vs-blind gap 11 → ~4 点**。

**② 7/6 Exp 2 Margolus block CA：验证"迁移性"**

换一个结构完全不同的可逆系统（block/partitioning CA，没有长程 carrier），问同一个配方还成不成立。3 个 free-form baseline（双向 GRU / LSTM / 小 Transformer）都给足预算（120 epoch）、单步都到 ~99%，但在 `T ∝ L` 的长程 compose 下全部崩掉（守恒 → ~0–1%，精度到 L=384 时逼近随机），结构化 block-CA 保持 **100/100**。

结论诚实地记为**同一配方、不同 backbone**（block-partition vs carrier scan），而不是"发现了新结构"——这回答了 proposal 里"每个系统是否需要各自的结构"这个问题，对 Margolus 的答案是"不需要"。

**③ 7/7 是全周最重的一天（22 commit），三件大事**

- **bolt-on 对照实验 → 全库 reframe**。为回答"谁都能给 LSTM 加个守恒约束"这个质疑，做了一个对照：把守恒**强行焊到** free-form 模型上（top-N 投影）。结果是可以焊上、但**救不回精度**——Margolus 上守恒被强制到 100%，精度仍在 L=384 塌到 ~51–56%（结构模型 100%）；BBS 上守恒 100%，精度 79–92%，仍低于守恒 carrier 的 100%。于是整个 repo 的 headline 改了：**exactness（严格性）才是关键，conservation（守恒）只是可以焊上去的副产品**。bolt-on 对照从此定为每个深水实验的**标准动作**。
- **Exp 3 Toda lattice：一个有范围的负结果**。真正的目标（让一个连续可积系统变成可学模型）。先写预注册（falsifiable criterion + 障碍日志），再动手。Step 1 积分器 + Lax 矩阵自检通过（能量 ~1e-5、动量 ~1e-14、isospectral ~1e-6）。Attempt 1（action-angle，无论学出来还是给真值）失败 = F2；Attempt 2（Neural-Lax）技术上也失败 = F2′，**但挖出了真发现**：一个普通 free-form composing stepper 在连续 Toda 的时间外推上本来就能做到 MSE ~0.003，**根本没有留给结构的空隙**。这确认了 roadmap 里的 discrete→continuous 隐忧——在离散 BBS/Margolus 上有效的判别器，不迁移到光滑连续流。按预注册**停手，不掉进无底洞**。
- **benchmark 从翻车到验证通过**。先做旗舰系统 multi-soliton BBS 真值 + 首个 leaderboard（结构模型 100/100/100/100，GRU/LSTM/Transformer soliton-IoU 只有 1–33%），随即自己做泄漏审计，发现在 plain BBS 上结构模型 = 硬编码求解器、blind 也能 100 分 → **自己下令"停止叫它 benchmark"**。接着引入外部 review 的 Phase 0 gate 修订版：path A（colored rule）不可逆、失败；**path B（finite-carrier）5 seeds 通过 gate（K=3）**。最终结果：结构 conserving carrier 在精度 / 球数 / 振幅含量三项 **100 ± 0**；carrier-blind 泄漏审计只有 **40 ± 3**（60 点的真实学习裕度）；bolt-on 能把球数钉在 100% 但振幅含量只恢复 **0.7 ± 0.8%**。这是全项目**第一个正面的、多 seed 确认的结果**，边界也写清楚了：只验证了 Tier 1（一个系统、K=3），且只对离散可积成立。

## Key Lessons This Week

- **7 月的"投出一篇论文"提前兑现，但走的是另一条腿**。月度计划写的是用 Paper 2（可逆性/可积性）先切一篇出去，实际 Week 17 投出去的是 **Paper 1（TMLR，7/8）**，Paper 2 同期推到了动笔。计划锁定了"投一篇"这个目标而不是"投哪一篇"，结果哪条线先熟就先投——**目标定在结果上、不定在路径上，是这次能提前兑现的原因**。

- **周报的数据源有两个盲区，这次差点漏掉头条**。`physlit/` 主 repo 本周 0 commit，但真实进展全在被 gitignore 的独立子仓库 `latex_tmlr/`（匿名化 commit）和不进版本库的 `private/`（outreach 记录、投稿计划）里，投稿日期本身只有推文有。**只跑 git log 会把"投出了论文"误判成"静默"**。以后写周报必查：主 repo git log + gitignored 子仓库 + private/ 笔记 + blog analysis/ + Twitter + 平台通知邮件。

- **一周内三次主动作废自己的结果，诚实审计变成了工作方式**。7/5 发现 Test 3 的规则泄漏（blind 也能 100 分）→ 整个测试作废重做；7/7 做完首个 benchmark leaderboard 后自己做泄漏审计 → **自己下令"停止叫它 benchmark"**；多 seed 跑完主动把单 seed 的过度声明修回（100 → 94±5，gap 11 → ~4）。这一周里，"把自己的结果证伪"比"做出新结果"占的时间还多——但这正是 Tier 1 那个结论最后能站住的原因。

- **预注册 → 负结果 → 记录但不用**。Toda 两次尝试都失败（F2 / F2′），按预注册**停手**（明确写下"no bottomless pit"），负结果完整写进 repo 但不进论文。而且失败里挖出了真发现：连续 Toda 上 free-form 本来就能解到 MSE ~0.003，**根本没给结构留空隙**——判别器不从离散迁移到连续。**一个诚实的负结果，把项目的边界画清楚了，比一个可疑的正结果值钱。**

- **exactness vs conservation 是本周最大的认知产出**。bolt-on 对照（把守恒强行焊到 free-form 模型上）一次性回答了"谁都能加个守恒约束"这个质疑：能焊上，但救不回精度。于是整个 repo 的主张从"结构守恒不漂移"升级成"**结构严格性可以 compose 而不漂移，连给对手焊上守恒都追不上**"——守恒是副产品，严格性才是那个焊不上去的东西。这个 reframe 之后，bolt-on 对照被定为每个深水实验的标准动作。

- **冷邮件的价值在第二次触碰，不在第一次**。7/3 Tegmark 正面回信并主动 CC 引荐 Martin Rees，7/10 reply-all 接住——这是 outreach 名单里第一次跑通"冷接触 → 回复 → 引荐 → 二次触碰"的完整链路。名单自己的复盘也很清醒：已回复的三位都是学术讨论型，按"找伯乐/引荐人"的目标契合度其实不高，重心要转向有资源、在招人、且不跟自己抢同一个 benchmark 的那批。

- **求职这条线的真实体量，git 完全看不见**。周报此前只看到 `Study_Notes` 那 5 个复习 commit，而实际上本周投了 13 个岗位、走完第一场 HM 面，且求职在 Notion 里被明确定为**第三主线**（有三档法、有每周固定节奏、有目标公司表和 waitlist）。这是继 `latex_tmlr` 之后**第二个 git 盲区**——凡是"对外动作"（投稿、outreach、投递、面试），留痕的地方都不是版本库。

- **天花板由题材决定，不由发挥决定**。本周单条最高的推文是 2002 世界杯黑哨（20K，非 AI 内容），比所有文章引流帖都高一倍多；同期五篇文章全压在"AI 概念科普"这条 6–15k 的带子里，总量卡死在 42.5k。**没有哪篇是失手，是这五篇的天花板本来就都在 15k 以下。** 一篇 40k 的高天花板 vertical，顶得上这周三篇。
